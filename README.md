# 开饭小工具（AutoSkip）

Android 14 适配的自动化工具集，基于 **无障碍服务（AccessibilityService）**，纯本地运行、不联网、不上传任何数据。

## ✨ 功能总览

### 一、自动跳过弹窗
- 识别并自动点击弹窗中的「跳过 / 关闭 / 下次再说 / 不再提醒」等按钮
- **图标 X 兜底**：纯图标（无文字）关闭按钮也能识别点击
- **返回键兜底**：同一弹窗点击无效时，自动改用返回键关闭
- **验证码保护**：检测到滑块 / 拼图验证时，整个弹窗不点
- **事件节流 + 主动轮询**：事件与处理分离（IO 线程），即使无障碍事件流静默也能持续识别，不再卡住

### 二、规则管理
- **普通规则**：匹配文字 → 点击（支持精确 / 包含匹配、限定包名）
- **条件规则**：有 X 且含 Y → 执行动作（点文字 / 点图标X / 按返回键）
  - 「有」和「且」都支持多关键词（| 分隔）；「有」任一命中，「且」全部命中
  - **延时检测**：检测到条件后等 N 秒，仍存在才执行（默认 3 秒，0=立即）
  - **规则级冷却**：同一规则触发后 2.5 秒内不重复（防返回键连按）
  - **一键导出/导入**：导出到剪贴板 / 从文本导入（可选清空，同名跳过）
  - **仅抖音/白名单内生效**（开关，默认开）
  - 内置规则：登录框→返回、推荐+转发到日常/举报→返回、关注+作品/粉丝→返回 等
- **学习模式**：手动点一次目标按钮，自动生成规则
- **白名单**：仅对指定应用生效（支持通配符，如 com.qihoo.magic.*），避免误点系统 UI / 桌面
- 内置抖音全家桶：官方抖音、极速版、360 分身大师所有分身

### 三、短剧自动倍速
- 抖音短剧中自动长按视频（限屏幕左侧 15%~55%，避开右侧头像/互动栏）→ 菜单选 3x
- **按集数间隔呼出**：识别图片版菜单默认每集、其他版默认隔 5 集（均可配置）
- **新剧自动重置**：检测到新剧（集数回退 / 发布者变化）从第 1 集重新计数
- 多重开关：自动长按、自动点击倍数、自动进入短剧
- 菜单项黑名单：推荐 / 合拍 / 举报等绝不误点
- **退出短剧全暂停**：检测到「退出短剧 / 返回并退出」时，暂停**所有操作**（长按呼出菜单、倍数选择、条件规则、普通规则），直至重新出现「集 / 全 / 免费」的短剧页面再恢复

### 四、自动分身（分身大师）
- 批量创建抖音分身，自动改名、安装、跳过弹窗
- 支持「按数量」或「按序号截止」两种停止模式
- 悬浮窗实时日志（可滚动 / 一键复制 / 可调高度）、单条与平均耗时统计
- 系统弹窗坐标可配置，适配不同设备

### 五、记录统计
- 每次跳过的 App、时间、命中规则
- 今日 & 累计次数，可清零

### 六、保活机制
- **前台保活服务**（START_NOT_STICKY）：提升进程优先级防冻结，划掉后不重建、不跳前台
- 事件流中断时由**主动轮询**自愈

## 🔧 构建（GitHub Actions）

项目已内置工作流 .github/workflows/build.yml：

1. 把本工程推送到 GitHub 仓库
2. 进入 Actions 标签页，触发 Build APK
3. 构建完成后自动发布 GitHub Release（含签名版 APK）：
   - 从 Releases 页面直接下载 AutoSkip-x.x.x.apk
   - 使用 shortdrama 密钥签名，可覆盖安装

本地构建（如已装 Android SDK）：

    gradle assembleRelease

## 📱 安装与使用

1. 安装 APK
2. 打开 App → 点击「去开启无障碍服务」→ 找到「开饭小工具 · 自动跳过」并开启
3. **自动跳过**：首页开关 + 规则 / 白名单配置
4. **短剧倍速**：首页卡片进入，打开总开关，目标选 3x
5. **自动分身**：首页卡片进入，配置数量 / 序号后开始运行
6. 首次使用建议开启 **学习模式**：切到目标 App 手动点一次，自动生成规则

## 🛡️ 保活说明（重要）

Android 14 及各家 ROM 对后台限制较严，请额外做以下设置以保证长期存活：

- **电池设置**：本应用 → 不受限制 / 无限制
- **自启动管理**（小米/华为/OPPO/vivo 等）：允许本应用自启动
- **最近任务**：将本应用锁定（下拉锁图标）
- **省电模式**：关闭系统的智能省电对无障碍服务的限制

> 提示：分身任务会「全部关闭」后台，请先锁定本应用再开始分身，避免被一起清理。

## 📐 技术栈

- Kotlin + Jetpack Compose (Material 3)
- Room（规则 / 条件规则 / 日志）
- DataStore（配置持久化）
- AccessibilityService（核心：自动点击 / 手势 / 短剧）
- GestureDescription（长按、坐标点击）
- 单线程调度器（串行化节点树访问，避免多协程并发死锁）

## ⚠️ 合规提示

本工具仅在用户主动开启无障碍服务后，于本地识别并操作界面，
不采集、不联网、不上传任何数据，请遵守各应用的使用条款，勿用于违规用途。
